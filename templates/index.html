EquityX AI Assistant

A Telegram-based virtual assistant developed using Python, Flask, Firebase Firestore and Google Gemini. The application helps users access trading and investment-related information while allowing administrators to monitor activity through a web dashboard.

Open Admin Panel

Core Features

Chat Assistance

Handles user queries and generates responses through Gemini AI.

Activity Tracking

Stores user interactions and provides usage statistics.

Cloud Database

Firebase Firestore is used for managing users, chats, feedback and support requests.

Technology Stack

Python • Flask • Firebase Firestore • Google Gemini • Telegram Bot API • HTML • CSS
